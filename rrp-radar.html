Part 1

Install & use

What this is

A Chrome extension for the AFS sales team that runs inside the Shopify admin draft-order (quote) builder. As you add products to a draft order, it quietly looks up each product's live pricing and drops a small badge on the line showing whether it's on sale, the RRP (compare-at) it's discounted from, and the dollar saving. A tidy panel in the corner tallies the total saving across the whole quote — the number worth saying out loud to the customer.

Install on Chrome / Chromebook

  1. Download the zip above and unzip it. You should get a folder with manifest.json, a src/ folder, and an icons/ folder directly inside (no nested subfolder). On ChromeOS, open Files, find the zip, right-click and choose Extract.
  2. Move the unzipped folder somewhere permanent before loading it into Chrome. Chrome reads the extension files directly from the folder you point it at — it does not copy them. If that folder is later deleted or cleaned up, the extension breaks. On a Chromebook, put it in My Files › Extensions; on Mac, your home folder; on Windows, Documents.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode using the toggle in the top-right corner.
  5. Click Load unpacked (top-left) and select the unzipped folder — the one containing manifest.json.
  6. The AFS RRP Radar tile appears. Click the puzzle-piece icon in the toolbar and pin it so it's always handy.
Already set for GAF and Revel. Gym and Fitness and Revel storefronts are pre-configured out of the box. If you also quote on Force USA (or any other store), add it once in Options — see Set up your stores below.

How to use it

  1. Open a Shopify admin draft order — either a new one or an existing quote (admin.shopify.com/store/…/draft_orders/…).
  2. Add products to the order as you normally would.
  3. Each line picks up a badge within a second or two: ON SALE — was $X, save $Y on discounted lines, or not on sale otherwise.
  4. Glance at the RRP Radar panel in the bottom-right corner for the running total — total RRP, total now, and Customer saves across the whole quote.
  5. If a line doesn't update after editing, click Rescan on the panel (or the Rescan button in the extension popup).
The number that closes. "This build lists at $12,400, but with what's on sale today you're paying $9,900 — that's $2,500 back in your pocket." RRP Radar puts that figure in front of the rep automatically.

Set up your stores

RRP Radar reads live pricing from each brand's public storefront. It already knows GAF and Revel. To add another store (e.g. Force USA), or to change a mapping:

  1. Right-click the AFS RRP Radar toolbar icon → Options (or open the popup and click Options & store mapping).
  2. Under Store → storefront mapping, add a row. The store handle is the bit in the admin URL: admin.shopify.com/store/gymandfitness-au/…. Map it to that brand's storefront web address (e.g. https://www.forceusa.com).
  3. Set the currency if it isn't AUD, then click Save settings.

Troubleshooting

The panel says "No line items detected yet"

Make sure you're on the draft-order editor with at least one product added, then click Rescan. RRP Radar reads the product links in the line list — including Shopify's newer web-component admin, which nests them in Shadow DOM. If badges still don't attach after a reload, ping Gary or Josh with a screenshot.

A line shows "no live price"

That line couldn't be matched to a storefront product — usually a custom/one-off item, a product not published to the online store, or an unusual title. On-catalogue products match automatically. Hover the badge to see why.

Nothing appears at all

Check the extension is enabled (click the icon → the Enabled toggle), that the store is mapped in Options, and reload the draft order once after installing.

Still stuck?

Message Gary or Josh with a screenshot of the draft order and we'll sort it.

How it works

Chrome Extension (MV3) Content Script Service Worker Storefront AJAX API Read-only

1 Architecture

Content Script
reads draft-order line items in the admin, draws badges + the total panel
→asks
Service Worker
looks up pricing off the storefront (cross-origin, cached)
→reads
Storefront
public product pricing: RRP + promo per variant

Manifest V3. A content script runs on the Shopify admin, finds each draft-order line, and asks the background service worker for that product's pricing. The service worker does the lookup from the extension context (so the cross-origin call to the storefront is clean) and hands back RRP, promo and the saving. The content script paints a badge on each line and keeps a running total in the corner panel.

FileRole
manifest.jsonMV3 config, storefront host permissions, content-script registration
src/content.js / content.cssDetects line items, injects badges + the total-saving panel
src/background.jsService worker: resolves RRP vs promo pricing from the storefront, caches results
src/options.html / options.jsStore→storefront mapping, currency, on/off
src/popup.html / popup.jsToolbar popup: enable toggle + rescan

2 Where the pricing comes from

Entirely from each brand's public storefront, no API key required. Each draft-order line exposes its exact variant ID in the admin, and the worker matches that against a catalogue it pulls once (and caches) from the storefront's public product feed:

// build a variant→price index once, cached 30 min
GET /products.json?limit=250&page=N   // id, price, compare_at_price
// fallback for anything not in the feed:
GET /search/suggest.json?q={title}  →  GET /products/{handle}.js

Resolving by variant ID is exact and immune to title quirks — the old title-search path returned nothing for products with a ™ or unusual characters in the name, which showed as “no live price”. If compare_at_price is higher than the current price, the line is on sale and the difference is the saving. This is the same pricing the customer sees on the website, so the rep’s quote and the storefront never disagree.

Verified against a live 5-line order. Every catalogue product prices correctly — e.g. the Force USA G20 Pro resolves to was $8,499, now $5,999, save $2,500. Service items (e.g. “Assembly & Rubbish Removal”) have no storefront product, so they correctly show no price.

3 Privacy & security

  • Read-only. The extension never writes to Shopify — no edits to draft orders, prices, or anything else.
  • No accounts, no API keys, no tokens. It reads the same public pricing anyone can see on the website.
  • No backend and no tracking. Settings (your store mappings) stay in your browser via Chrome sync storage.
  • It only runs on Shopify admin pages, and only calls the AFS brand storefronts you've mapped.

4 Status & limitations

Version 0.2 — verified live. Line-item detection now works against Shopify's current admin, which renders the order editor as web components inside nested Shadow DOM. Badges attach under each product and the summary tallies the total saving. Confirmed end-to-end on a live multi-line draft order.
  • Custom / one-off line items (not real catalogue products) won't have a storefront price to match — they show "no live price".
  • Products not published to the online store can't be read from the storefront.
  • Pricing reflects the storefront's current default price. Customer-specific or draft-order-level manual overrides aren't compared against RRP.
  • Internal AFS use only. Not published to the Chrome Web Store.
