Install & use

What this is

A Chrome extension that lets you dictate into any text field. Press Alt+Q, speak naturally, and formatted text appears at your cursor. It handles punctuation, capitalisation, bullet points, and tone automatically.

FeatureDetail
TriggerAlt+Q to start / stop dictation
TranscriptionChrome's built-in speech engine (free, no API cost)
FormattingGemini Flash cleans up the text (fractions of a cent)
LanguageAustralian English by default
Works inGmail, Google Docs, forms, comment boxes, WhatsApp Web, Slack, anywhere with a text field
Why is it so cheap? Most dictation tools (like Whisperflow) pay per minute of audio transcription. VoiceType flips that: the expensive audio step uses Chrome's free built-in engine. Only the cheap text-cleanup step goes through Gemini, costing fractions of a cent per use.

Install on your Chromebook

  1. Open Files, find voice-dictation-extension.zip, right-click it and choose Extract. You should get a folder with files like manifest.json, background.js, etc. directly inside it (no nested subfolder).
  2. Move the unzipped folder somewhere permanent before loading it into Chrome. Chrome reads the extension files directly from the folder you point it at — it does not copy them. If that folder gets deleted or cleaned up, the extension breaks.

    Where to put it:
    ChromeOS / Chromebook: Open Files, go to My Files, and create a folder called Extensions. Move the unzipped folder there so the path is My Files › Extensions › VoiceType. Do not leave it in Downloads — ChromeOS can clean that folder out automatically.
    Mac: Move it to your home folder, e.g. ~/VoiceType.
    Windows: Move it to Documents\VoiceType.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode (top-right toggle).
  5. Click Load unpacked (top-left) and select the extracted folder (the one containing manifest.json).
  6. The VoiceType tile appears. You can pin it to the toolbar if you like (puzzle-piece icon, then pin).
Important: set the shortcut scope. After loading, go to chrome://extensions/shortcuts. Find VoiceType's "Start / stop voice dictation" entry. The shortcut box should show Alt+Q, but the scope dropdown next to it may be blank. Change it to "In Chrome" and click Update. Without this, the shortcut won't fire.

Set your Gemini key one time

  1. Grab the Gemini API key from the VoiceType card in LastPass. It looks like AIza...
  2. On the VoiceType tile in chrome://extensions, click Details, then Extension options. (Or right-click the toolbar icon and choose Options.)
  3. Paste the key and click Save.
Don't have access to the Asana task? You can also create your own free key at aistudio.google.com → Get API key.
Make sure the key starts with AIza. Keys that start with AQ. or other prefixes are OAuth tokens and won't work. You need a Google AI Studio API key specifically.

How to use it

  1. Click into any text field (Gmail compose, a form, a comment box, WhatsApp Web, etc.).
  2. Press Alt+Q. A small "Listening..." pill appears at the bottom-right of the page.
  3. Speak naturally. Say things like "new line" or "bullet point" and the formatter will handle them.
  4. Press Alt+Q again to stop (or just pause speaking for a moment). The cleaned, formatted text is inserted at your cursor.
Clipboard backup. The formatted text is also copied to your clipboard. If a particular editor doesn't accept the direct insertion (e.g. Google Docs' canvas), just press Ctrl+V to paste.

Good to know

  • First time on a new website: Chrome will ask to allow the microphone. Click Allow once and it's remembered for that site.
  • Reload any tabs that were already open before you installed the extension.
  • Won't work on Chrome's own pages (chrome://..., the new-tab page, Chrome Web Store). That's a Chrome restriction, not a bug.
  • Needs an internet connection (the speech engine is cloud-based).
  • You can change the shortcut any time at chrome://extensions/shortcuts.

Customise formatting

Open the extension's Options page (right-click toolbar icon, or via chrome://extensions Details).

Formatting style

The large text box controls how your dictation is cleaned up. The default behaves like Wispr Flow: fixes grammar, removes filler words ("um", "uh"), and formats lists when you're clearly listing things. Edit it freely to change the tone, add specific instructions, or adjust the formatting rules.

Per-site tweaks

Add rules that only apply on specific websites. Each rule has a match (any part of the web address) and extra formatting instructions. Two examples are included out of the box:

MatchBehaviour
whatsappCasual, conversational tone like a text message
mail.googleProfessional email tone with courtesies

Add your own for Slack, Asana, LinkedIn, or any site where you want a different voice.

Model

Choose between Gemini models in the dropdown. gemini-2.5-flash is recommended (best quality). gemini-2.5-flash-lite is the cheapest option if you want to minimise costs.

Troubleshooting

Alt+Q does nothing

Go to chrome://extensions/shortcuts. Find VoiceType and make sure the scope dropdown is set to "In Chrome" (not blank). Click Update. This is the most common issue on ChromeOS.

Raw text appears instead of formatted text

The extension falls back to raw (unformatted) transcription if the Gemini key is missing or invalid. Check your key in Options. It should start with AIza... and come from aistudio.google.com.

Microphone not working

Chrome prompts for mic access per site. If you accidentally blocked it, click the lock/tune icon in the address bar, find Microphone, and change it to Allow. Then reload the page.

Text doesn't appear in Google Docs

Google Docs uses a custom canvas editor that can reject direct text insertion. The text is on your clipboard. Press Ctrl+V to paste it.

Extension disappeared after an update

If you reload the extension from a new folder path, ChromeOS gives it a new internal ID and clears its saved settings. You'll need to re-enter your Gemini key in Options.

The extension has four files that do everything:

FileRole
manifest.jsonWiring: permissions, Alt+Q command binding, content script injection
background.jsCatches the hotkey, calls Gemini with the raw text, returns formatted text
content.jsCaptures speech via the browser engine, shows the listening pill, inserts the result
options.html/jsSettings page: Gemini key, model, formatting style, per-site rules

2 Cost model

Traditional dictation tools like Whisperflow charge per minute of audio transcription (the expensive step). VoiceType inverts this:

StepProviderCost
Audio to textChrome's built-in webkitSpeechRecognitionFree
Text cleanupGemini Flash (text-only, ~100 tokens per dictation)Fractions of a cent
The free tier is generous. Google AI Studio gives you a free API key with a per-minute rate limit. For normal dictation use, you'll likely never hit it.

3 Privacy & security

  • Microphone audio goes to Google's speech service (the same one behind ChromeOS dictation). It is not recorded or stored by the extension.
  • Only the resulting text is sent to Gemini for formatting. No audio leaves the browser.
  • Your API key is stored locally on the device in chrome.storage.local. It is never written into the extension's code files or sent anywhere except to Google's Gemini API.
  • The Gemini formatting prompt includes a prompt-injection guard: the model is instructed to treat dictated text as content to format only, not as instructions to follow.

4 Limitations

  • No effect on Chrome system pages (chrome://..., new-tab, Chrome Web Store).
  • Requires internet (the speech engine is cloud-based).
  • The free speech engine is good but not perfect. The Gemini pass cleans most errors.
  • Google Docs insertion may rely on the clipboard fallback (Ctrl+V).
  • Chrome asks for microphone permission once per website (remembered after that). An "ask once globally" upgrade is possible in a future version.
  • Reloading the extension from a new folder clears saved settings (Gemini key must be re-entered).
